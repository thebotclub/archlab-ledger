## Question (pre-registered)

Does a model's internal residual-stream state at the query position encode
whether its own MQAR retrieval answer is correct — ABOVE AND BEYOND what output
confidence (logits at the same position) already predicts — and is that signal
present only in models that are ABOVE the capability transition?

KILL CRITERION (verbatim from LAB3-CHARTER.md): "AUC ~0.5 above threshold =>
dead, report the null."

Sanity gate on the reproduction itself (must pass before any probe cell is
interpreted): T1,T2 recall >= 0.95; F1,F2 recall in [0.03, 0.12]. If violated,
the reproduction failed; STOP and report, do not probe around it.

Additionally, candidate arms save a checkpoint every 10% of phase-A steps.
Any intermediate checkpoint whose recall on the probe panel P80 falls in
[0.20, 0.95] is designated MID-TRANSITION and gets the full probe battery
(bonus cells, same thresholds). Selection rule fixed here: at most the 2
checkpoints per run closest to recall 0.5 from opposite sides.

## Probe data (fixed before capture)

- Panels: fresh MQAR panels generated by the ak data.py generator with
  **panel salt 3900** (Lab 3 seed block; never used before), n = 512 sequences
  each, seq_len 384, queries 40, nkey 160:
  - P80: pairs=80 (the training distribution; control difficulty)
  - P96: pairs=96
  - P112: pairs=112
  - P128: pairs=128 (hardest that fits: 128*2+1+80 = 337 <= 384)
  The ladder exists because transitioned models sit at recall 1.0 on P80 and an
  error class must come from somewhere; harder panels are the pre-declared way
  to obtain it.
- Instance = one query. Features captured at the QUERY-KEY position q_j (the
  position whose next-token prediction is scored), i.e. apos_j - 1.
- Representations: residual stream after embedding and after each of the 8
  blocks (9 capture points, d=384 each), fp32, eval mode, no dropout.
- Label: correct_j = (argmax over vocab of logits at q_j == true value token).
- Per-cell recall is recomputed on these panels and reported; sealed-battery
  numbers are not touched.

## Split (fixed; no peeking, no re-splitting)

Split BY SEQUENCE (all 40 queries of a sequence stay on one side) to prevent
within-sequence leakage: 60% train / 40% test, single split, rng seed **3901**.
The same split indices are used for every layer, every model, every panel.
Any hyperparameter selection happens strictly inside the train side.

## Probe and baselines (fixed)

- Probe: L2-regularised logistic regression on the 384-dim layer activation,
  implemented in torch (venv has no sklearn; the shared venv is not modified).
  Class imbalance handled by inverse-frequency class weights in the loss.
  Lambda selected from {1e-3, 1e-2, 1e-1, 1.0} by class-weighted log-loss on
  the last 25% of TRAIN sequences (validation-within-train), refit on full
  train, evaluated ONCE on test.
- Metric: ROC AUC on test instances (rank statistic; class-weight-free and
  threshold-free).
- BASELINE (the comparison that decides mundane vs genuine): identical
  logistic-regression pipeline on 3 output-confidence scalars at the same
  position: [top-1 log-softmax, top-1 minus top-2 logit margin, entropy of the
  softmax]. Also reported: raw single-scalar margin AUC (no fitting).
- Descriptive covariate (NOT a verdict input): geometry baseline — logistic
  regression on [token distance from queried key's value position to q_j,
  query index j]. Reported to flag structural-correctness confounds.

## Pre-registered thresholds and readouts

Power rule: a (model, panel, layer-family) cell is POWERED iff the minority
class (errors or corrects) has **>= 30 instances overall AND >= 12 in the test
split**. Otherwise the cell is marked UNDERPOWERED — not passed, not failed.

For FLOORED models (F1, F2) on P80 (the control cells):
- Expected: probe AUC ~ 0.5 at every layer (correct answers are chance hits;
  there is nothing to know).
- CONTROL PASS: all layers' test AUC in [0.35, 0.65].
- If any layer exceeds 0.65: instrument alarm (probable leakage or label
  artefact) — diagnose before interpreting ANY transitioned cell.

For TRANSITIONED models (T1, T2) on the hardest POWERED panel:
- DECODABLE: best-layer test AUC >= **0.75**.
- GENUINE INTERNAL SIGNAL: DECODABLE AND best-layer activation AUC >=
  (3-feature confidence-baseline AUC + **0.10**).
- MUNDANE (confidence-only): DECODABLE but activation AUC < baseline + 0.10.
- DEAD (charter kill): every layer's AUC <= **0.60** in every POWERED
  transitioned cell.
- If NO transitioned cell is powered (even at P128 and no mid-transition
  checkpoint qualifies): verdict UNDERPOWERED, reported as such, with the
  observed error counts. No threshold is relaxed post hoc.

Verdict precedence (fixed): instrument alarm > underpowered > dead > mundane >
genuine. A "genuine" verdict requires BOTH transitioned models (T1 and T2) to
clear the GENUINE bar independently in at least one common layer index — a
one-model signal is reported as SUGGESTIVE only.
